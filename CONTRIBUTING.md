# Contributing

1. Read the skill and the relevant reference.
2. Keep the change within one clear purpose.
3. Add a test for changed runner or usage behavior.
4. Run `npm run check`.
5. Describe the change, test result, and remaining gaps in the pull request.

Use Node.js built-ins. Keep account data and job output out of commits. Use short, direct English
in operator instructions. A live Claude test is optional unless the change affects CLI behavior.
State when a live check was not run.
